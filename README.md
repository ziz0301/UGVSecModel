# UGV Security Modelling Based on AVHARM

This project presents an experimental application of the **AVHARM (Autonomous Vehicle Hierarchical Attack Representation Model)** framework to Unmanned Ground Vehicle (UGV) security modelling.

Using a representative UGV architecture and attack scenario, the project explores how AVHARM can be adapted to model UGV components, communication networks, vulnerabilities, and potential attack paths.

The website provides the UGV system architecture, sample scenario data, and an interface for exploring the security model using AVHARM.
